# 自行撰寫，不 fork tack

我們評估了 [elvisperlika/tack](https://github.com/elvisperlika/tack)（MIT），決定不以它為基礎、也不複製其程式碼，而是自行實作。它的核心綁定與顯示機制與需求衝突：以 0.4 秒輪詢偵測切換（快速切換時延遲與閃爍）、一般視窗以標題或文件路徑為識別、瀏覽器網址刪除 query 與 fragment、只假設單一螢幕且未處理全螢幕、一次只顯示一張便利貼。這些正是本 App 最需要做對的部分，改寫幅度接近重寫，fork 只會留下錯誤的假設。

## Consequences

- 因未複製任何程式碼，不需附 tack 的授權聲明；若日後沿用其任何片段，須補上 MIT 版權與許可聲明。
- 便利貼的外觀與互動（拖曳、淡入淡出）可參考 tack，UX 概念（如「待找回」區塊）可參考商業軟體 TackNote，但兩者都只參考、不沿用。
